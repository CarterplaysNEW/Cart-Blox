# Cartblox A browser "classic brick" game site: home page, Games, Catalog, CartStudio (beta), multiplayer, Robux/Tix. ``` index.html the website (GitHub Pages serves this). Your Render URL + Firebase config are BUILT IN. config.js optional overrides (server URL, Firebase, money testing knobs) Dockerfile builds the multiplayer server on Render (keep the exact name "Dockerfile") server/server.js the multiplayer server (Node + WebSocket) server/package.json render.yaml optional Render blueprint database.rules.json Firebase Realtime Database rules (paste into the Firebase console) .dockerignore / .nojekyll ``` ## 1. Website (GitHub Pages) Upload ALL these files to your repo (replace the old ones, keep the folders). Settings > Pages > deploy from `main`, root. Use THIS index.html. (cartblox.html is only the offline preview, it never goes online.) ## 2. Game server (Render) - already done https://cart-blox.onrender.com is public and working. Nothing to change. Free Render services fall asleep after ~15 minutes with no players. The first visitor after that waits up to a minute; the game tells them and lets them play solo meanwhile. When you push to GitHub, Render redeploys the server automatically. ## 3. Firebase - TWO things to do once 1. Rules: Firebase console > Build > Realtime Database > Rules. Replace everything with the contents of `database.rules.json` and press **Publish**. (New rules were added for published games.) 2. Anonymous sign-in: Firebase console > Build > Authentication > Get started (if asked) > Sign-in method > **Anonymous** > Enable > Save. Publishing games needs this; it is how the site knows only YOU can update YOUR games. Players never see a sign-in screen. ## Checking everything Open your site and click **Status** at the very bottom. It tests the Render server, the Firebase database and anonymous sign-in, and tells you exactly what to fix if something is red. ## Money (Robux & Tix) - Everyone starts with 0. Playing any game earns +10 Tix every 20 minutes and +10 Robux every 25 minutes (only while active; not while testing in CartStudio). - Uploading an item (shirt, pants, T-shirt, face, hat, hair, accessory) costs 50 Robux or 150 Tix. Publishing games is free. - Trade Tix for Robux on the My Money page (3 Tix = 1 Robux). - To test quickly, set `startTix: 500` or `timeScale: 60` in config.js (then set them back to 0 / 1). - Note: balances are stored in each player's browser, so a determined player could edit their own. Fine for a fan project. ## Publishing games In CartStudio press **Save**. The first time, the Publish Game box asks for a Title and Description; press Publish and the game appears on the Games page for everyone. Every Save after that updates the published game. File > Game Settings changes the title/description; File > Save a Copy starts a new unpublished copy. ## Tools (gear) - 9 tools: Classic Sword, Slingshot, Paintball Gun, Rocket Launcher (Combat); Speed Coil, Gravity Coil, Cartblox Cola, Confetti Popper (Fun); Trowel (Building). - In a game: press 1-9 (or tap a slot) to hold a tool, click/tap the world to use it. Right-drag still turns the camera. - Cartblox Tools (on the Games page) gives you every tool, has training dummies, and counts KOs. - Catalog > Gear > Tools: "Add to Backpack" (free, up to 9). Your gear comes with you into games that allow gear: Baseplate, Cartblox Tools, and community games whose creator ticked "Allow gear" when publishing. - CartStudio Toolbox > Tools (givers): drop a Tool Giver pad into your place; players get that tool when they touch it. Change which tool it gives in Properties > Tool. - IMPORTANT: the server got new message types for tool hits and effects. Commit the new server/server.js to GitHub; Render redeploys automatically (or press "Manual Deploy" in Render). Until then tools work, but hits and effects are not shared with other players.
